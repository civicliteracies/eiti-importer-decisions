Which source carries each country–year declaration — the individual Summary Data Files, the API extract, or both.

Both sources SDF only API only Year joined EITI

Every country-year in the API extract now has a Summary Data File. The years that once had none on record — Nigeria's pre-2012 declarations, Ethiopia 2014–2015, and Mongolia 2010 — have since been published by EITI and are included here. Four country-years still show as API-only above — Argentina 2018, Liberia 2019, and Mali 2017–2018 — because their only Summary Data File uses the v2 template rather than a v1 one; the declarations themselves are on record. Cohort years follow the reporting period's end year, EITI's own convention.
